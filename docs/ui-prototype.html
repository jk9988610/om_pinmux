需求组 / 约束栏 / 脚位图 是什么关系？

它们是同一批角色的三种视图，不是父子关系，也不是包含关系。角色清单来自 options.json；需求组按「我要什么功能」用 role_id 分组，约束栏按「芯片允许这个功能落在几只脚上」用 allowed_pins 数量自动分档，脚位图只是把这批角色摆到 32 个物理位置上。

需求组
按功能分组→ 同一批角色 →约束栏
按脚数分档→ 同一批角色 →脚位图
按物理位置

所以选中其中一个视图，另外两处会同步高亮同一批角色：点需求组 → 约束栏筛出该组角色、脚位图高亮它们的合法脚；点某个角色 → 脚位图只高亮这只角色能用的脚。
