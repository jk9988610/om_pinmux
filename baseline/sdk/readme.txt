20260115

Changes:
    1. 增加了上电长按左中键1S，进入测试模式的代码，具体的操作模式参考<OM6239测试模式按键操作>
    2. 修复了SENSOR硬件读取异常导致光标偶尔抖动的问题
    3. 上个版本修复滚轮快滚问题时，出现滚轮不松开的问题，这里解决了
    4. 堆栈大小调整，避免栈溢出导致程序异常的问题
    5. 增加看门狗部分代码，兼容A3版本的芯片，A3版本的看门狗是常开的
    6. 优化了FLASH部分的操作
    7. 更新了电压检测部分代码，增加了A3芯片的兼容，具体的数据可以参考代码里边的LVD表格，电量更新逻辑
        也做了对应的更新，没有5V充电的情况下电量只能降不能升，5V充电的情况下电量只能升不能降，升降均
        有个延时，默认3S,具体的电压阈值以及电压去抖延时看客户要求去更改
    8. 增加蓝牙快联测试功能，快联测试后开机蓝牙继续广播
    9. 删除蓝牙电量定时上传的功能，解决部分主机休眠异常唤醒的问题
